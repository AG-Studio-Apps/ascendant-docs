# Ascendant — site

The overview page, the privacy policy and the licence agreement for
[Ascendant](https://github.com/AG-Studio-Apps/ascendant), served by GitHub
Pages.

Three pages and one layout. There is no docs collection and no manual: the app
explains itself, and a site that repeats it goes stale the first time the app
changes.

## Running it

```
bundle install
bundle exec jekyll serve
```

## Things worth knowing

- **No custom domain.** This is a project site, so it lives under the
  repository name. `url` and `baseurl` in `_config.yml` both have to match the
  repository, and both change together if it is renamed.
- **The App Store button hides itself.** `app_store_url` is empty until
  release, and every link to the store is wrapped in a check for it, so the
  site never offers a link to nothing.
- **The screenshots come from the app's own capture pipeline**, halved in size.
  They are regenerated by running the screenshot workflow in the app
  repository, not edited here, so the site cannot drift from what the app
  looks like.
- **The legal dates live in `_config.yml`**, as `legal_version` and
  `legal_effective`, and are rendered on both documents. Change them there.
